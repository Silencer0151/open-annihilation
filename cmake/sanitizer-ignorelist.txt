# Where an OA_SANITIZERS build with Clang leaves alignment unchecked
# (-fsanitize-ignorelist). The canonical records keep their packed layouts,
# so many of their fields sit at offsets their types do not align to, and
# the code below binds references to those fields and reads them in place.
# Everywhere else, the readers of game files included, a misaligned load or
# reference stops the test that makes it. Drop a directory once its code
# copies packed fields out instead of reading them in place.
#
# The standard library headers are listed too: a misaligned reference handed
# to them is reported where the caller binds it, unless the caller is listed.
