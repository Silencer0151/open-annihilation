# Hand-written edits of the layout pass (tools/layout/layout.py).
#
# A hunk is `@@ pre|post <path> [note]`, then `<<<`, the text to find, `===`,
# its replacement, and `>>>`. pre hunks are matched against today's tree
# (old paths and names) before the mechanical rewrites; post hunks against
# the laid-out tree (new paths and names) after them and before the aliases
# are added. The text to find must occur exactly once; a hunk whose
# replacement is already there counts as applied. An empty replacement
# removes the lines found; an empty find appends the replacement to the
# file.
#
# What the pass does by rule needs no hunk here: a source that moves to
# another module leaves its old CMakeLists.txt, with the targets it leaves
# empty; the new modules' build files are in tools/layout/files/.
